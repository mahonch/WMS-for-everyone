# Warehouse Management System (WMS)

## Веб-информационная система управления складом

Дипломный проект по разработке системы управления складом  
с использованием **Spring Boot**, **Vue.js** и **PostgreSQL**

---

# О проекте

Данный проект представляет собой веб-информационную систему управления складом, предназначенную для автоматизации складских процессов.

Система позволяет:

- вести учет товаров;
- управлять складами и локациями;
- оформлять приемку товаров;
- управлять остатками;
- создавать задания на комплектацию;
- строить маршруты комплектовщика;
- выполнять аудит действий пользователей.

---
