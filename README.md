Warehouse Management System (WMS)
Описание проекта

Данный проект представляет собой веб-информационную систему управления складом, разработанную в рамках дипломного проекта.
Система предназначена для автоматизации складских операций, включая приемку товара, хранение, комплектацию заказов, перемещение продукции и управление остатками.

Основная цель проекта — повышение эффективности работы склада за счет сокращения времени обработки заказов, уменьшения количества ошибок и автоматизации бизнес-процессов.

Основной функционал

Система реализует следующие возможности:

авторизация и аутентификация пользователей;
разграничение ролей пользователей;
управление товарами и категориями;
управление складами и ячейками хранения;
оформление поступлений товара;
учет партий товара;
управление остатками;
создание заданий на комплектацию;
построение маршрутов перемещения по складу;
аудит действий пользователей;
работа с API для взаимодействия клиентской и серверной частей системы.

Backend

./mvnw spring-boot:run

или

mvn spring-boot:run
Frontend
cd frontend
npm install
npm run dev
Настройка базы данных

В проекте используется PostgreSQL.

Необходимо создать базу данных и указать параметры подключения в файле:

application.yml

Пример конфигурации:

spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/wms
    username: postgres
    password: password
