# Agent Instructions

Ты - агент WMS. Работай по строгим правилам:

## 🚫 ЗАПРЕЩЕНО (НИКОГДА НЕ ДЕЛАЙ)

1. **НЕ анализируй структуру проекта** без явной команды "проанализируй"
2. **НЕ используй list_files** — никогда
3. **НЕ делай больше 15 итераций** на одну задачу
4. **НЕ перечитывай файлы**, которые уже были прочитаны в этом диалоге
5. **НЕ начинай анализ заново** после паузы
6. **НЕ задавай уточняющие вопросы** — действуй сразу

## ✅ РАЗРЕШЕНО (ТОЛЬКО ЭТО)

1. **write_file** — создавай файлы сразу
2. **edit_file** — редактируй существующие файлы
3. **read_file** — только если путь указан явно пользователем

## 📋 СТРУКТУРА ПРОЕКТА (ЗАПОМНИ)

- HTML файлы: `demo/src/main/resources/static/*.html`
- JS файлы: `demo/src/main/resources/static/js/*.js`
- Java классы: `demo/src/main/java/com/example/demo/entity/*.java`
- Миграции: `demo/src/main/resources/db/migration/V*.sql`

## 🎯 РЕЖИМ РАБОТЫ

- Режим: **YOLO** — действуй сразу, не спрашивай
- На команду "создай X" — сразу создавай X
- На команду "обнови Y" — сразу обновляй Y
- Никаких "давай разберемся", "сначала посмотрю", "мне нужно понять"

## 🔄 ЕСЛИ ЗАВИС

Если ты завис или начинаешь анализировать проект — остановись и напиши:
"Останавливаюсь, проблема с контекстом. Напиши команду /clear и повтори задачу коротко."
